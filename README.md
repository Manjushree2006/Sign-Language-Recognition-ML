# ✋ Hand Gesture Recognition using Machine Learning and MediaPipe

A Machine Learning project that performs real-time hand gesture recognition using MediaPipe for hand landmark detection. The project demonstrates gesture detection through computer vision techniques and machine learning, providing an efficient and interactive recognition system.

---

## 📌 Project Overview

Hand gesture recognition enables computers to interpret human hand movements for intuitive interaction. This project utilizes **MediaPipe** for extracting hand landmarks and combines it with Machine Learning techniques to recognize different hand gestures accurately.

The repository contains implementation notebooks, Python scripts, project documentation, and supporting materials developed as part of an academic Machine Learning project.

## 🚀 How to Run

1. Clone or download the repository.
2. Install Python.
3. Install the required libraries:

```
pip install opencv-python mediapipe numpy
```

4. Open the Jupyter Notebook or run the Python script.
5. Allow camera access if prompted.
6. Perform hand gestures in front of the webcam.

---

## 📊 Workflow

1. Capture video from webcam
2. Detect hand landmarks using MediaPipe
3. Extract landmark coordinates
4. Process features
5. Classify hand gestures
6. Display prediction in real time
